# 🧪 Rick & Morty Explorer

A web application to explore **Rick & Morty** characters and episodes using the [Rick and Morty API](https://rickandmortyapi.com/).  
Users can search characters by name, filter by species, and view all episodes.

---

## ✨ Features

- 🔍 Search characters by name
- 🧬 Filter characters by species (Human, Alien, Robot, Mythological Creature)
- 🖼️ View character images, species, and status
- 📺 View episodes with name, code, and air date
- 🎨 Responsive grid layout for both characters and episodes
- 🌑 Dark theme for immersive look

---

## 🛠️ Technologies Used

- **HTML5** – structure
- **CSS3** – styling & layout
- **Vanilla JavaScript** – logic & API calls
- **Rick and Morty API** – data source

---


---

## 🚀 How to Run

1. Clone or download the repository
2. Open the project folder
3. Open `index.html` in a browser  
   *(No server setup required)*

---

## 🌐 API Endpoints Used

- `/character` – for character data  
- `/episode` – for episode data  

Data is fetched dynamically based on search input and filters.
